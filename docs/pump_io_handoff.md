## set / get 接口

| 同事已提供的接口 | 用途 | 应用适配层职责 |
| --- | --- | --- |
| set_do(index, value) | 设置数字输出 | 逻辑 DO1～DO4 映射到索引 0～3；核对有效电平及负载驱动 |
| get_do(index, value) | 读取 DO 寄存器状态 | 不能等同于线圈或机构已动作 |
| set_ao_current(index, microamps) | 设置 AO 电流 | 输入范围 0～20000 µA；安全值及 4～20 mA 模式下低于 4000 µA 的行为待验证 |
| get_ao_current(index, microamps) | 读取 AO 工程量寄存器 | 不是外部实际电流反馈 |
| get_ai_current(index, microamps) | 读取电流型 AI | 保留采样时间、结果码，完成 4～20 mA 标定和断线判定 |
| get_di(index, value) | 读取数字输入 | 核对有效电平、采样时间和有效性 |

## 对接要点

| 项目 | 约定 / 待填写 |
| --- | --- |
| 分工 | 同事的 M31 驱动保持原样；702 应用适配层对接 IoPort，组装采样、输出与反馈 |
| 调用线程 | 阻塞式 set/get 放独立 IO 任务；控制任务只读缓存、提交请求 |
| 函数返回 | 区分成功、失败、超时、无新数据；读取失败不能用 0 冒充正常值 |
| 输入标定 | AI 原始值 → 物理量 → 控制位置 -100..100；CAN 状态角度另按标定提供 |
| 输出更新 | 执行最新请求；停止覆盖旧动作；禁止重放过期运动请求 |
| 执行确认 | 保留请求序号与反馈时间；set 成功或 get 设定值回读不直接作为实际执行确认 |
| 安全输出 | 每路 DO 安全电平、AO 安全值、断网输出和远端看门狗待定 |
| 超时配置 | 授权 auth_ms、指令 motion_ms、采样 io_ms 待定；当前输出租期取 io_ms |
| 轴行程 / 滞回 | min_pct、max_pct、start_tol、stop_tol 待定；start_tol > stop_tol |
| 轴动作保护 | ack_ms、travel_ms、stall_ms、grace_ms、reverse_ms、min_progress、wrong_tol 待定 |
| 轴力度 | effort：0..1000 归一化请求；实际 DO/AO 映射待定 |
| 未配置行为 | 轴参数全零时禁止动作；缺少有效采样、限位或执行反馈时禁止启动 |
| 故障复位 | 确认故障原因消除及安全输出生效；重新授权、新指令后才允许动作 |
| 待接入 | 按本表接入 702 IO 适配层、标定 / 反馈、PWM 驱动接口、StatusCodec 状态编码和 .ino 启动调用 |
