## 配置含义与默认行为

- 四轴分别为左翻斗、左转舵、右翻斗、右转舵。CAN 的 -100/0/100 是最低/中位/最高或最左/中位/最右的位置目标；0 不等同于停机。
- 每个传感器分别保存低、中、高电流。当前暂用 4000/12000/20000 uA，沿用既有分段线性算法；可改为非对称三点或递减电流，重复点和非单调点会被拒绝。
- position_ready=true 只表示启用暂定百分比换算，不表示完成实物标定。真实角度未确定，angle_ready=false，不生成假的角度反馈。
- 左右 Settings 各含 bucket/steer 参数。默认启动误差 4、停止误差 2、最小进展 1、反向阈值 3；这些单位均是归一化位置，不是角度。
- 翻斗 effort=1000（现有 DO 仍是开关输出）；转舵 effort=250。等待执行确认 2000ms、最大动作 20000ms、无进展 4000ms、启动宽限 1000ms、换向等待 300ms，全部为待验证的暂定值。
- AO 与 PWM 的三个端点独立，steer_ao_scale / steer_pwm_scale 分别决定是否随 effort 插值。Effort 的公式为“停止值 +（方向端点 - 停止值）× effort / 1000”；Fixed 在动作期间直接采用方向端点。
- 当前 PWM 方向端点暂定为 500/1000，即 50% 占空比。Effort=250、停止值=0 时结果为 12.5%，不能解释为 12.5% 机械力度。频率仍为 0，等待现场确认。
- 两侧 output_ready=false，App702 将实际运行的四轴配置置为 Disabled。配置文件仍保留完整参数供审核；DO、AO、PWM 不会因本轮配置而被启用。
- alarm_interlock=false：油位、油温、滤堵保留原始状态、错误和时间，不产生机构报警联锁。需要增加联锁时显式启用并填写 alarms_ready 和极性。位置无效、超时、反向和无进展监测仍属于闭环要求。
- AppConfig 的外部调用者如果原先直接填 pump_control，需要改填 left_control/right_control。仓库内调用已一起更新。

## 液压压力的协议结论

PJ400无人控制通信协议_20260903.docx 第 3.2 节明确为“喷泵状态反馈，喷泵系统发送”。0x06069002/0x06069082 的字节 4–5 是实测液压泵压力，分辨率 1000 Pa，按协议高字节在前上报；它不是上位机的目标压力设定。

已有 AI1（左）和 AI4（右）压力采集保留。传感器电流与压力满量程尚未确认，pressure_ready=false，仅原始电流有效时保存原始电流。没有添加“增压至目标即停”的控制规则、虚构的泵输出通道或额外 CAN ID。

已有编码器仍要求相应状态帧字段完整且有效；只取得一个压力值并不保证整张 0x06069002/82 状态帧已可发送。齿轮箱等字段、协议布局确认及 SPN/FMI 的剩余工作见原准备记录。
